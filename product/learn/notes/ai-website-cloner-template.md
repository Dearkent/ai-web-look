# 读码笔记：JCodesMore/ai-website-cloner-template（2026-11-26）

只读了说明（README）和给编程助手的流程文件（.agents/skills/clone-website/SKILL.md），没有安装、没有运行。许可证 MIT。读的版本：253bdbd（2026-11-25）。

## 它是什么
- 一个 Next.js 项目模板 + 一份给 AI 编程助手看的“复刻网站”流程。不是能被我们调用的库或服务。
- 每复刻一次：编程助手开浏览器看原站 → 写出 Next.js 组件 → 截图并排对比 → 修差异，反复直到像。

## 流程（用我们自己的话概括）
1. 先列“原站页面 → 本地页面”的对照表，不覆盖已有的东西。
2. 先观察再动手：桌面和手机尺寸都看，量关键尺寸和算好的样式，记录区块顺序、字体、版面、交互状态。
3. 先把公共的东西定下来（字体、宽度、颜色、共用组件），再分区块搭。
4. 同尺寸、同滚动位置、同状态下并排对比；先修最大的差异（几何、缺的区块、字体换行、图片裁切），再修间距和动画；最后跑真实操作（导航、菜单、折叠、轮播）。

## 和我们的关系
- 不能原样装进工作台：
  - 它要求用原站的真实文字和原站加载的字体、图片、视频，等于照搬别人的内容和品牌素材；它自己的说明也写明不能用于钓鱼、冒充、把别人的设计当成自己的。公开平台给陌生用户“一键复刻任意网站”风险太大。
  - 技术路线不同：它产出 Next.js 工程、每次要一个编程助手长时间跑；我们是“图纸 → 静态站 → 自我纠错”。
  - 用户的规矩：第三方代码只做笔记、不运行。
- 值得学的：
  - “先观察、量算好的样式、记一页简报”——和我们 dom_probe.js 读头部网站的做法一致，已经在用。
  - “同尺寸并排截图对比、先修最大的差异”——可以加进我们的自我纠错（和参考站/上一版对比）。
- 安全的落地方式（待用户确认再做）：
  - 参考风格 / 组合元素：只读版面和样式数字，用用户自己的内容生成原创网站，不拷贝文字、图片、logo、字体；和参考站太像时提醒。
  - 自己的网站搬家：先验证域名归属（DNS TXT 记录），再允许完整搬迁。
