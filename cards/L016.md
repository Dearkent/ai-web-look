## 根因
- 沿指针链走的 while 没防环。
- `--filter=blob:none` 的无检出克隆上做 `git grep HEAD`，git 会逐个去网上取对象，几分钟都不结束。
- subprocess 超时只杀了 shell，孙子进程还握着输出管道，读输出会一直等。

## 做法
- 每个 while 在同一行或上一行写“# 有界：理由”，checks/loop_audit.py 强制检查。
- subprocess 一律带 timeout；shell 里 git clone/fetch、curl、wget 一律套 timeout。
- 需要整组杀掉时用 start_new_session=True + os.killpg（brain.run_bounded）。
- 无检出克隆只用 git ls-tree 列文件、git show 读单个文件，不做全库 git grep。
- 自己测试脚本时用 `timeout N python3 -u`。
