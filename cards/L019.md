## 根因
Python 按模块名缓存；别处先 import 了标准库 copy，之后 from copy import 就拿到标准库，报找不到函数。错误信息又被我加的 2>/dev/null 吞掉，一时看不出原因。

## 做法
- 文件名用业务词（copywriter.py），不用 copy、types、json、test 这类名字。
- 调试时不要把错误输出丢掉。
