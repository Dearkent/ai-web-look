## 根因
products.csv 用显示名和“A + B”组合引用风格与落地页（如 “Hero-Centric Design + Conversion”），其中一部分名字在词表里不存在；styles.csv 里 8 个旧风格 ID 已弃用并迁到 landing 域。直接拿推荐结果写进图纸，会写进不存在或已弃用的 ID。

## 做法
- 名称 → ID 统一走 product/tools/kb.py：先整串匹配别名，再逐段匹配，本域找不到就跨域并跟随弃用跳转。
- 解析不了的段落写进 kb_trace.unresolved，置信度至少降一档；影响大的进 open_questions。
- 检查器遇到弃用 ID 时给出替代 ID 和应填的字段。

## 反例（什么时候不适用）
用户直接点选风格卡片时，ID 已确定，不需要解析。

## 固化
已固化：kb.resolve_combo + check_blueprints 的弃用提示
