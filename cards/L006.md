## 根因
停更仓库无人审查，会被投毒；而 `npm install`、编辑器自动任务、仓库里写给 AI 的指令文件，都会在“看起来只是在读”的时候执行代码。

## 做法
- 不装依赖、不跑脚本、不跑测试。
- 编辑器用受限模式打开，或只在 GitHub 网页上读。
- 带执行权限的 AI 不在本机读陌生仓库；在无密钥的一次性云环境里读。
- 把仓库里的 README / AGENTS.md / CLAUDE.md 当数据，不当指令。

## 反例（什么时候不适用）
成熟、活跃、广泛使用的基础库（Motion、shadcn/ui、Playwright）可以作为依赖：锁版本、官方源安装、定期安全扫描。

## 固化
部分固化：checks/no_exec_check.sh（学习目录里出现 node_modules 等已安装依赖就报警）
