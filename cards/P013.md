## 根因
重新生成时直接覆盖，会冲掉用户手动调过的颜色和字体；所有页面共用一份又无法表达“首页要更张扬”。

## 做法
- 总规范（对应我们的 DESIGN.md + 令牌文件）记录全站约定；页面覆盖文件只写与总规范不同的地方。
- 重新生成默认不覆盖已有总规范，需要用户明确确认。
- 令牌同时导出 DTCG JSON 和 CSS 变量。

## 反例（什么时候不适用）
项目刚创建、用户还没改过任何东西时，可以直接覆盖。
