## 根因
开发环境里什么都装好了，测试全过不代表用户能用。这一轮第一次在全新的 Python 3.9 上跑，立刻发现两处会让用户一打开就崩的问题：生成器用了 3.12 才允许的 f-string 写法；依赖 jsonschema 没声明、启动器也不检查。

## 做法
- 测试从打包好的压缩包开始，解压到新目录，HOME 也换成空目录。
- 用给定的 Python 新建空虚拟环境：先自检（应报缺依赖并给出能直接复制的命令）→ --setup 自动装 → 没装 Playwright 时照样能生成并说明 → 装上后完整流程带浏览器检查 → 导出。
- 检查只写了该写的地方（~/.aisite；程序文件夹里只多学习记录）。
- 压力：60 句各行业、英文、表情、超长、注入、只有标点的需求，各配随机修改，不崩、图纸 0 错误，抽样真实浏览器 0 问题。
- 在 3.9、3.11、3.13 上都跑一遍。

## 反例（什么时候不适用）
macOS 和 Windows 的真机测试还是要在真机上做；这里是 Linux 上的近似。
